# Showcase data

These small snapshots are copied from the tracked `results/*/example.json` files
in the two simulator branches so the Pages site stays self-contained.

`routine-visuals.json` contains display windows transcribed from three tracked
Routine reports in `routine/results/log/`. It is used by the hero carousel to
draw the canonical chain and non-canonical branches with their real heights,
miners, and hashes.

`routine-example.log` is a byte-for-byte copy of
`routine/results/log/example.log` and is the downloadable Routine report.
